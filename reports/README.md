# Publication Outputs

This directory contains the compact, publication-facing outputs intentionally
tracked by Git.

- `figures/` stores stable PNG and vector SVG copies used by the README,
  portfolio, and written analysis.
- `tables/` stores selected compact CSV tables needed to inspect reported
  values behind the figures.

These files are generated by the checksum-verified reporting commands and must
not be edited by hand. A successful reporting run first writes a new immutable
snapshot under `data/evaluations/`, records its source lineage and output
checksums, and then refreshes the stable copies here. Changes to publication
outputs should be committed with the code and documentation that produced and
interpreted them.

Large raw data, portfolio paths, backtests, and complete evaluation snapshots
remain local under `data/` and are excluded from Git.
