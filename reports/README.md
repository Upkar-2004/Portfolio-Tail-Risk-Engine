# Publication Outputs

This directory contains the compact, publication-facing outputs intentionally
tracked by Git for release `v0.1.0`.

- `figures/` stores stable 300-DPI PNG and vector SVG copies used by the
  README, portfolio, and written analysis.
- `tables/` stores selected compact CSV tables needed to inspect the values
  behind reported figures.

These files are generated by checksum-verified reporting commands and must not
be edited by hand. A reporting run first writes a new immutable snapshot under
`data/evaluations/`, records its source lineage and output checksums, and then
refreshes the stable copies here. Publication-output changes should be committed
with the code and documentation that produced and interpreted them.

Large raw data, portfolio paths, backtests, and complete evaluation snapshots
remain local under `data/` and are excluded from Git.

## Main-text figures

### Full-sample predictive-accuracy inference

- [`predictive_accuracy_dm_comparison.png`](figures/predictive_accuracy_dm_comparison.png)
- [`predictive_accuracy_dm_comparison.svg`](figures/predictive_accuracy_dm_comparison.svg)
- [`predictive_accuracy_dm_comparisons.csv`](tables/predictive_accuracy_dm_comparisons.csv)

Formal pairwise VaR quantile-loss and joint VaR-ES FZ0 comparisons. Marker fill
encodes Holm-adjusted decisions; daggers flag decisions that change under the
lag-zero HAC sensitivity analysis.

### Subperiod VaR calibration

- [`subperiod_exception_rate_heatmap.png`](figures/subperiod_exception_rate_heatmap.png)
- [`subperiod_exception_rate_heatmap.svg`](figures/subperiod_exception_rate_heatmap.svg)
- [`subperiod_exception_rate_intervals.png`](figures/subperiod_exception_rate_intervals.png)
- [`subperiod_exception_rate_intervals.svg`](figures/subperiod_exception_rate_intervals.svg)

The heatmap shows observed minus nominal exception rates. The interval figure
adds pointwise 95% exact binomial intervals and matched visual reference bands.
Both displays are descriptive secondary analysis.

- [`subperiod_predictive_first_place_summary.svg`](figures/subperiod_predictive_first_place_summary.svg)
- [`subperiod_predictive_scores.csv`](tables/subperiod_predictive_scores.csv)

Calendar-year first-place counts for VaR quantile loss and joint VaR-ES FZ0
loss. The companion table preserves the score magnitudes and ranks.
